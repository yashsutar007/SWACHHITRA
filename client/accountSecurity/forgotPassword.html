SWACHHITRA · ACCOUNT SECURITY

Recover access.

SWACHHITRA staff accounts can be activated or recovered through the authority responsible for their current assignment.

Recovery codes are single-use, expire in 30 minutes, and are accepted only while the account's required assignment remains active.

PASSWORD RECOVERY

Forgot password?

Enter your account email to request normal email-based reset instructions when email delivery is configured. For staff accounts without email delivery, use the assignment-authorized recovery code process below.

I already have a recovery code Authority: issue a staff code

Drivers: request a code from the Sanitary Inspector responsible for your assigned Ward. Sanitary Inspectors: request a code from the Assistant Commissioner who assigned you. The authority must sign in to SWACHHITRA before issuing a code.
